## Documentation intent

The current documentation should keep the project focused on the `travel-planner` MVP:

- structured data before rendering;
- planning before booking;
- human-in-the-loop revision;
- explicit assumptions and validation;
- no live inventory, booking, browser automation, or marketplace integrations in the first milestone.
